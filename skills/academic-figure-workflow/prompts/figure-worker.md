# Optional parallel figure work

Use only when parallel agents are explicitly authorized and independent work benefits. Do not split one sequential figure merely to use agents.

Give each worker the actual scientific sources and visual references, requested artifact, editable/export requirements and nonoverlapping output paths. Share established labels/colors and the regions that must remain intact. A short task message is enough; no handoff schema or mandatory IDs.

The worker views the references, draws or analyzes the requested scope, inspects real outputs and returns files plus material unresolved issues. The main agent checks cross-figure consistency and delivers the integrated result. Neither creates an unrequested approval gate.
