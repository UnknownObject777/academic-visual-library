# 有色语义分区图示风

A surface/color variant for semantic regions. Inherit the composition and drawing language; use `illustrated-modular` when that is the actual overall treatment.

Pair a soft region fill with a darker outline/title and optional accent. Reuse the same pair for the same role across figures. Use labels, boundaries, or shapes so grouping survives grayscale.

Useful pairs from the I1 palette:

| Pair | Fill | Outline | Title |
|---|---|---|---|
| Blue | #EDF4FB | #194166 | #163E64 |
| Green | #F3FBF0 | #3B7D23 | #2F681D |
| Peach | #FBE3D6 | #A94417 | #9E3F13 |
| Purple | #F5ECF5 | #77206E | #65185E |

Activate the pairs needed by the scientific roles. This variant does not require a three-column composition, a rainbow of all available tokens, or hand-drawn illustration. For an editorial drawing language, see [编辑手绘模块风](编辑手绘模块风.md).
