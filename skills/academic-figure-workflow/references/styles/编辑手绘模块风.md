# 编辑手绘模块风

Canonical profile: `illustrated-modular`.

Use for an editorial scientific explanation when the requested drawing language favors soft semantic regions, expressive line art, and clear narrative emphasis.

- Coordinate low-saturation region fills with darker outlines and titles.
- Use rounded editorial line art and a readable heading style.
- Give the central explanation greater visual attention when there is a clear focal mechanism; use balanced treatment for genuine peers.
- Group subcards only where a real hierarchy benefits from them.
- Prefer flat surfaces without shadows for this preset; adapt to an inspected reference if it differs.
- Add a few meaningful scientific anchors rather than an icon in every node.

The I1 pairs in [palettes.md](../palettes.md) are a starting point. This drawing language does not require a robot, laboratory apparatus, fixed three-column layout, hero-area percentage, or a prescribed number of panels.

For source-based style transfer, preserve composition and mark language while taking all method content from the target source.
