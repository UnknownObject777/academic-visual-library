# Academic Figure Content Analysis

Read only the supplied material needed to answer the figure's reader question. Use actual operations and claims to identify what deserves visual emphasis, not section headings as an automatic pipeline.

Separate verified results, proposed mechanisms and hypotheses. Preserve training/inference, observation/prediction and other relevant boundaries. Source important labels, formulas and directed relationships. Sparse notes can support a high-level conceptual diagram; missing numerical results do not block that diagram and cannot justify invented plots.

Adapt composition to real sequence, comparison, hierarchy, loop or interaction. No mandatory Figure 1, panel count, three-stage framework or report format. A full manuscript does not require a multi-figure plan when one diagram was requested. Carry supplied reference style forward without importing its method.

Analysis-only work returns a concise visual recommendation with evidence locations and material uncertainty. If drawing was requested, proceed to [the designer](../academic-figure-designer/SKILL.md) and render/inspect/deliver in the current task. Do not serialize a FigurePlan or impose an approval gate.

Use actual venue geometry when known; provisional size is a design choice, not an official requirement. Missing scientific information is handled by [missing-info-policy.md](../academic-figure-workflow/references/missing-info-policy.md).

For text-to-editable-PPT work, carry the source-backed labels, causal order, focal mechanism and conceptual/measured distinction into [the workflow's native branch](../academic-figure-workflow/references/editable-ppt.md). Analysis is complete when these relations can be drawn without inventing an operation; a mandatory intermediate specification is not an additional deliverable.
