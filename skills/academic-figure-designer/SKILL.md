# Academic Figure Designer

Design from supported science and inspected references. Drawing requests finish the artifact through [the workflow](../academic-figure-workflow/SKILL.md), unless only advice was requested.

## Reference identity

Read the shared [style contract](../academic-figure-workflow/references/style-library/design.md). Identify silhouette, typography, density, marks, surfaces, color roles and arrow language. Use [style-to-layout](../academic-figure-workflow/references/style-to-layout.md) to resolve observations into reusable values. A reference can lie outside bundled examples.

Transfer appearance; derive modules, causality and topology from target content. Exact redraw preserves source science; local edits preserve correct untouched regions. A familiar diagram motif is not evidence for a target operation.

**Done:** style and science have separate authorities, and concrete values support coherent panels and revisions.

## Spatial hierarchy

Give the novel mechanism room while preserving necessary context. Choose sequence, shared scene, loop, hierarchy or comparison from the method. Comparable panels share relative anchors, arrow specifications and colors. Distinguish frame/flow alignment from centering of intentionally different data geometry.

Insets of the same scientific space reuse underlying geometry through affine viewports. Preserve relative distances, classes and query positions. Distinguish alternative cases from simultaneous outputs.

**Done:** the reading path answers the intended question; panels are comparable; arrow direction, endpoints and strength convey supported meaning. When the user requests uniform arrows, preserve any scientific weight distinction through another agreed mark.

## Medium and finish

For editable PPT read [native execution](../academic-figure-workflow/references/editable-ppt.md); use real text and physical-size typography. For illustrations use [image execution](../academic-figure-workflow/references/codex-image-workflow.md); measured plots use real data. Disclose raster textures, photos or externally edited plots.

Optional [styles](references/styles/index.md) supply treatments, not mandatory layouts. Inspect the actual selected reference image instead of copying only its hex values.

**Done:** the render matches reference identity at thumbnail and reading size, remains scientifically faithful and passes [shared render checks](../academic-figure-workflow/references/render-audit.md). Continue the current task without restarting routing or approval.
