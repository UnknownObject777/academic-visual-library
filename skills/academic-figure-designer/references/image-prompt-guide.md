# Repair observed visual errors

Describe the actual correction in normal language and use the best current render as the edit target. Pass the reference image where supported; preserve correct regions.

| Observed defect | Useful correction |
|---|---|
| Colors match but style does not | Identify mismatched silhouette, density, mark/illustration language, surfaces, strokes or typography and reproduce the actual reference treatment |
| Generic boxes replace a shared scene | Restore the reference's spatial composition while preserving target relationships |
| Source method leaks into new method | Remove imported modules/labels and use target scientific content |
| Missing/reversed edge | State exact endpoints, direction and meaning |
| Unreadable or wrong text | Specify essential exact labels, reduce nonessential text; use suitable editable tools when requested |
| Production instructions become labels | Separate visible strings from rendering instructions and remove leaked text |
| Local edit changes untouched regions | Restore preserved regions and scope the correction explicitly |

This is a repair aid, not a mandatory prompt template. Inspect the actual next result; repeated instructions do not guarantee fidelity.
