# Scientific visual vocabulary

Consult this vocabulary only when a visual anchor helps explain a sourced component. Labeled boxes, text-only nodes, and abstract shapes are valid; there is no required icon count or three-part visual formula.

| Sourced concept | Possible visual anchor | Avoid implying |
|---|---|---|
| Tensor or embedding | Stacked feature planes or a token grid | An exact shape, channel count, or dimension unless supplied |
| Attention or interaction | A small connectivity matrix or bipartite graph | Measured weights when the graphic is only conceptual |
| Encoder / decoder | Compression / expansion geometry | Unsupported network depth |
| Residual / skip path | A bypass connector between the actual endpoints | A feedback or optional path solely because a dashed style was chosen |
| Sequence, alignment, or MSA | Aligned abstract rows or supplied symbols | Fabricated biological sequences |
| Molecule / graph | A node-edge glyph or actual supplied structure | A real compound or validated interaction from a decorative glyph |
| Sampling / candidate selection | Candidate set with a selected item | A particular algorithm or sample count unless sourced |
| Model response / acquisition | A clearly schematic curve or surface | Empirical performance, calibrated uncertainty, or a specific equation |
| Decision / gate | A diamond with the actual condition | An invented threshold or Yes/No branch |
| Memory / persistence | State cards, a graph, or storage symbol | External database access or durable storage not established by the source |
| Physical experiment | The actual apparatus or a suitable abstract instrument | Wet-lab validation when only simulation was performed |
| Fixed / trainable / optional | A label plus a distinct line or fill treatment | A global convention unsupported by the figure legend |

Use one coherent drawing language: restrained vector marks, editorial line art, or the inspected reference's treatment. Scale supporting art to its explanatory importance. Labels, formulas, values, and apparatus come from the current source, not from this vocabulary.

Conceptual curves and surfaces should be identified as schematic when they might otherwise be mistaken for data. Render empirical graphs from actual data with plotting tools.
