# 现代前沿技术框线风

Canonical profile: `classic-technical`. Legacy name: 经典学术框线风.

Use for a compact technical diagram when the user or content calls for restrained geometry and precise connections.

- Prefer a white or near-white canvas, fine consistent outlines, and limited accents.
- Keep labels neutral and readable; distinguish hierarchy by spacing, line weight, and restrained group tints.
- Use squared or modestly rounded shapes and an orderly reading direction appropriate to the graph.
- Tensor blocks, matrices, residual arrows, and equations are useful only when supported by the method.
- Dense exact notation or editable output favors a vector renderer.

Suggested starting colors: text `#24323D`, structure `#1565C0`, arrows `#37474F`, group tint `#F5F8FC`. Adapt to the paper's existing palette.

This preset adds no model family, layer count, tensor dimension, or formula. Match the source's actual operations and the user's geometry.
