# 现代柔彩空气风

Canonical profile: `pastel-airy-ui`.

Use when the user or inspected reference favors open spacing, white cards, soft accents, and lightweight connectors.

- Keep the canvas light, with white or softly tinted cards and restrained borders.
- Carry semantic colors through pills, tokens, small regions, or curves rather than filling every surface.
- Use an understated type hierarchy and enough whitespace to separate groups.
- A faint shadow or dashed scope boundary is optional and should match the reference.
- A dark anchor card can identify a key operation when supported by the visual hierarchy.

Starting soft fills include peach `#FAE8DC`, periwinkle `#DBE7FB`, and gray `#E9E9EC`; pair with dark text `#24323D`. Check white text on any dark anchor against its actual fill.

Do not assume an agent, memory loop, black-box evaluator, or stacked context cards merely because this style is selected. Use the target method's structure.
